# Active categorical perception in an evolved CTRNN agent (JAX replication)

Replication of Beer (2003), *Adaptive Behavior* 11(4), in JAX.
A model agent with 7 distance rays and a small continuous-time recurrent neural
network is evolved to catch falling circles and avoid diamonds.
